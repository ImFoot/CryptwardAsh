# Cryptward · The Ashvault

A dark fantasy dungeon crawler with a Three.js 3D world, articulated characters, dynamic lighting, an authored campaign, and generated Expeditions.

Double-click **Play Cryptward.cmd** to play the local production build. See [PLAY_GUIDE.md](PLAY_GUIDE.md) for controls and development, [ART_NOTES.md](ART_NOTES.md) for asset provenance, and [BUILD_VERIFICATION.md](BUILD_VERIFICATION.md) for the latest checks.
