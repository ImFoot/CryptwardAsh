# Cryptward Complete Replit Handoff — Version 2.0

This is the only package Replit needs. It supersedes the earlier static-only starter packet while preserving its complete authored Level 1 and all original art.

## Hand it to Replit

1. Upload `Cryptward_Complete_Replit_Handoff.zip` to a new Replit project and extract it at the project root.
2. Paste `REPLIT_BUILD_PROMPT.txt` into Replit Agent.
3. Require milestone execution. The authored vertical slice is built and approved before procedural generation.
4. Use a 390 × 844 touch viewport for the primary acceptance test.

## Source-of-truth order

1. `MASTER_SPECIFICATION.md` for behavior, architecture, build order, and acceptance criteria.
2. JSON config/schema files for exact values and data contracts.
3. `levels/level-01-ashvault.json` for the canonical authored tutorial.
4. `asset_manifest.json` for all supplied visual assets.

The formatted DOCX is included for human review. Replit should primarily consume the Markdown and JSON files.
